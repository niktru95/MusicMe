# 🎸 Музыкальная теория для гитариста

Веб-тренажёр музыкальной теории на основе структуры проекта [programmingMe](https://github.com/niktru95/programmingMe) (vanilla JS, без сборки): выбирайте тему, отвечайте на вопросы прямо в браузере, отмечайте ноты на грифе и слушайте примеры через Web Audio.

**14 тем**, в каждой теория и упражнения (гриф, текст, выбор, слух, тап в ритм). Порядок задач перемешивается кнопкой 🎲, задачи «🎲 Тренировка» генерируют новый вариант по кнопке «🔁 Новый вариант».

## Темы

| Тема | Что тренирует |
|------|----------------|
| 🎵 Ноты и строй | EADGBE, названия нот на открытых струнах и на грифе, полутоны, октавы |
| 📏 Интервалы | полутоны, секунды, терции, кварты, квинты, септимы, октава |
| ☀️ Мажорная гамма | формула ТТПТТТП, ступени, тональности и знаки |
| 🌙 Минор и лады | натуральный/гармонический/мелодический минор, эолийский лад |
| 🧁 Трезвучия | мажор, минор, увеличенное, уменьшённое |
| 7️⃣ Септаккорды | maj7, 7, m7, m7b5 — состав и ноты |
| 🤘 Аккорды на грифе | баррэ, формы CAGED, корни на 6-й и 5-й струнах |
| ⛰️ Пентатоника | минорная и мажорная пентатоника, боксы, блюзовая нота |
| 🎼 Квинтовый круг | диатонические аккорды, функции T/S/D, ii–V–I, транспонирование |
| 🔁 Прогрессии и блюз | I–IV–V в открытых тональностях, 12 тактов, turnaround |
| 🔄 Обращения | бас не корень, малые формы на верхних струнах |
| 🌊 Лады | дорийский, миксолидийский, кратко фригийский |
| 🥁 Ритм | доли, восьмые, шаффл, смена на «раз» |
| 👂 Слух | интервалы и аккорды по аудио |

## Возможности

- 📝 Четыре типа заданий: ввод текста, выбор варианта (варианты перемешиваются), **клик по виртуальному грифу** (подписи нот скрыты, включаются кнопкой) и **тап в долю** под метроном
- 🎲 Генераторы задач: нота на грифе, интервалы, ступени тональностей, ноты трезвучий и септаккордов, интервалы и трезвучия на слух
- 🎼 Ответ нотами принимается в любом порядке и написании: `C# E G#`, `до-диез ми соль-диез`, `Db`, `H`
- 🔊 **Web Audio**: кнопка «Сыграть пример» в задачах и теории — слушайте ноты, интервалы, аккорды и гаммы
- 🎲 Случайный порядок задач и кнопка «Другая задача»
- 💡 Подсказки (по одной, задания помечаются «решена с подсказкой»)
- 📖 Ответ и пояснение к каждой задаче (показанное решение не засчитывает задачу)
- 👂 Слуховые задачи звучат от случайной тоники
- 📊 Точность по темам и фильтр «⚠️ С ошибками» для повторения
- 💾 Прогресс и последние ответы сохраняются в localStorage браузера
- 📱 Адаптивная вёрстка, работает с телефона

## Как запустить локально

Просто откройте `index.html` в современном браузере — никакой сборки и серверов не нужно.

Или через VS Code: установите расширение **[Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)**, кликните правой кнопкой по `index.html` → **Open with Live Server**.

## Деплой на GitHub Pages

1. Запушьте репозиторий на GitHub (ветка `main`).
2. Откройте репозиторий → **Settings → Pages**.
3. В блоке **Build and deployment**: Source — *Deploy from a branch*, Branch — *main*, Folder — `/` (root), Save.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ник>.github.io/<repo>/`.

## Как добавить свои задачи

Все задачи лежат в `js/data/` — по одному файлу на тему (`t01-notes.js`, ..., `t14-ear.js`).

Пример задачи:

```js
{ id: 'my-01', title: 'Нота на грифе', difficulty: 1, kind: 'text',
  question: 'Какая нота на 6-й струне, 3-й лад?',
  accept: ['g', 'g2', 'соль'],   // допустимые варианты ответа
  // kind 'choice' → options: [..], answer: <индекс верного>
  // kind 'fretboard' → board: [{ string: 1..6, fret: 0..12 }, ...], range: [0, 5] — все позиции нот в этих ладах
  // kind 'tap' → tap: { bpm: 80, pattern: [0, 1, 2, 3] }  (доли после 4 щелчков отсчёта)
  // ordered: true — для ответа нотами важен порядок
  // generate: function () { return { question, accept, ... } } — задача-генератор
  hints: ['Подсказка 1', 'Подсказка 2'],
  play: { note: 'G2' },          // необязательное аудио: note/interval/chord/scale
  // randomRoot: true             // сдвигать пример на случайную тонику (для слуха)
  solution: 'Ответ и пояснение.'
}
```

Форматы `play`:

- `{ note: 'A4' }` — одна нота
- `{ interval: ['C4', 'G4'] }` — две ноты подряд
- `{ chord: ['C4', 'E4', 'G4'] }` — аккорд
- `{ harmonic: ['C4', 'G4'] }` — две ноты одновременно
- `{ chords: [['C4', 'E4', 'G4'], ['C4', 'Eb4', 'G4']] }` — аккорды подряд
- `{ click: { bpm: 80, beats: 4 } }` — доли метронома (`sub: 2` — восьмые, `swing: true` — шаффл)

Раздел теории: `{ h: 'Заголовок', text: '...', code: 'таблица', play: {...}, diagrams: [...] }`.
Схема грифа: `{ caption: 'Открытый C (x32010)', frets: [0, 3], muted: [6], cells: [{ s: 5, f: 3, n: 'C', r: true }, ...] }` —
`s` струна, `f` лад, `n` подпись (если это нота, `validate.js` сверит её с клеткой), `r` — рамка корня.

## Автотесты

- `node validate.js` — проверка данных (структура задач, полнота ответов на грифе для «лады 0–12») и чекера. Запускается в GitHub Actions на каждый push.
- `index.html?selftest` — проверка в браузере: в заголовке вкладки появится `SELFTEST-OK` или `SELFTEST-FAIL: <что сломалось>`.
